# 模型思考配置与请求选择

关联 Issue #44、#41、#43。

## 配置归属

站点管理员在模型连接配置内维护思考能力，使用独立能力版本。
未配置与不支持均不发送新增参数；现有模型不自动推测或开启思考。
固定思考不可切换；开关、等级、预算使用该模型实际支持的选项。
显示名称只服务于该模型，不代表跨模型等效深度。

DeepSeek 仅使用真实等级 low/high/max，不把映射别名展示为不同等级。
该适配器的 disabled 选项表示关闭思考，不发送 reasoning_effort。
OpenAI 使用管理员确认的模型支持子集，不假设 Chat Completions 支持所有工具组合。
百炼预算范围须按具体模型填写；固定开启的模型不发送 enable_thinking。
仅流式百炼模型使用同一 Chat Completions SSE 协议聚合模型响应和工具参数，
保留最终 usage，思考内容不混入回答正文；Issue #49 起，受支持的上游思考字段独立展示。

## 请求边界

普通模型列表只返回类型、选项显示信息、默认选项、能力版本。
客户端发送 option ID 和版本，服务端校验并映射参数，禁止传任意上游参数。
省略选项使用管理员默认值；非法选项返回 422，过期版本返回 409。
请求开始后固定能力配置；后台改配置不改变已开始的 Agent 轮次。

参考官方文档：

- https://api-docs.deepseek.com/guides/thinking_mode/
- https://www.alibabacloud.com/help/en/model-studio/deep-thinking
- https://developers.openai.com/api/docs/guides/reasoning

## Agent 与历史消息

请求设置作为公开消息快照记录，历史消息保持空值。
DeepSeek 所需的 assistant/tool 消息序列使用现有模型凭据加密机制保存，
只在同一站点模型、模型名、适配器且开启思考时恢复；不同模型仅接收公开回答。
私有续传内容不出现在消息 API、导出、计费记录、日志或审计中。
原始推理 Token 不叠加到已包含它的 completion_tokens；没有额外档位收费。

## 思考展示与验证（Issue #49）

- DeepSeek、百炼明确返回的 `reasoning_content` 通过独立 SSE 事件展示，
  不读取或解密旧私有续传补造展示内容。OpenAI 等未提供展示字段的适配器不伪造思考。
- `thinking_delta`、`thinking_status` 沿用请求事件序号，关联每轮展示块；
  生成时展开，轮次完成收起；用户手动操作优先。正文、工具、后续思考按实际顺序排列。
- 展示正文通过现有加密能力单独保存到 `encrypted_display_thinking`；
  普通消息只返回块引用和安全诊断，展开后调用受会话权限控制的
  `GET /conversations/{id}/messages/{message_id}/thinking`。
  复制和默认导出仍只包含回答正文，旧消息不回填。
- 每轮诊断独立记录是否收到思考、合法推理 Token、流式方式和完成状态；
  缺失表示未报告，非法值不作零处理，推理 Token 只作诊断，不与输出总数相加。
- 管理员参数预览和运行时使用同一构建器，配置支持的档位子集，不推测具体模型能力。
  `POST /site/admin/llm-providers/{id}/thinking/preview` 只校验和预览，无上游调用。
- `/thinking/test` 只接受已保存版本和选项，使用固定问题，最大输出 1024 Token，
  每账号每分钟最多三次，按当前工作区正常计费；请求 ID 记录保证并发和重放不重复调用。
  无正文进入诊断、审计或测试结果；服务重启后的测试不自动重试。
- 接口接受参数、收到思考、返回推理用量是不同证据，测试成功不是档位质量评测。
  测试结果仅在版本和选项未变化时有效；不自动改档位或剥除参数重试。

## 输入区选择交互调整

原生下拉框虽然可以完成选择，但在高频问答输入区仍有后台表单的重量感。
改为同一行的模型名称与思考选项入口，锚定面板展示模型标识、实际选项值、
当前勾选及不可用原因；模型超过五项时支持搜索。手机入口至少 44px，
长名称省略，展开后完整显示，不增加虚构的性能评分或能力描述。

现有 UI 组件没有锚定选择入口，因此扩展既有 Radix Dialog 的 anchor 布局，
复用关闭、焦点与 Motion；新增业务组件只接收选项、当前值和变化回调，
不承担 API 请求、持久化或上游参数转换。无新增依赖。
模型和思考配置、请求参数、计费、默认模型均保持原有行为。
