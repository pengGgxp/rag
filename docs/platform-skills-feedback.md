# 平台 Skill 包与意见反馈

关联 Issue：#61、#62、#78。本文记录平台 Skill 包与建议收件箱。个人扩展关闭方案已被 #64 的[个人扩展约定](personal-extensions.md)替代；平台审核标准继续适用于平台包。平台包可携带文字、图片、普通二进制、示例归档及 Linux 脚本；脚本只在现有云电脑授权和隔离边界内执行。不包括管理员回复或通知，不改变 OCR、模型配置及计费规则。

## 管理与使用

站点管理员在 `/admin/skills` 搜索和筛选，进入独立详情页编辑名称、用途与 Markdown 指令。名称最多 64 字、描述 1024 字、正文 50000 字；新建默认停用。“保存并启用”可同时发布。可导入 UTF-8 `SKILL.md` 或常见 ZIP Skill 包（根目录或单层目录中包含 `SKILL.md`），解析 frontmatter 并保留包内相对路径资源；ZIP 上限 25 MiB、200 个文件、解压后总大小 20 MiB、单文件 5 MiB，不落盘。

包内文字资料在后台可检查和预览；启用后的模型先加载 Skill 方法和资料清单，再按需读取列出的文字文件，每次最多 12000 字，可按返回位置续读。相对 Markdown 链接必须能在包内找到目标。图片、普通二进制和 Linux 脚本作为只读任务资源保留，可随包启用并在现有云电脑中按 `/skills/<id>` 使用；ZIP/TAR 仅在内存中列出成员，不自动解压。结构错误、路径或链接越界、特殊文件、条目与展开大小超限和缺失引用阻止启用；平台可以保存不合格包为禁用草稿。导入只填充未启用草稿，不覆盖已保存内容，必须由管理员审核后明确保存并启用。

`/site/admin/skills` 提供分页列表、详情、创建、版本化修改和删除；`/import` 解析单文件或包草稿，`/review` 在保存前执行与启用相同的包检查。文件按二进制保存并在详情端 Base64 传输，不写入审计。`read_skill_resource` 仅可在本次 `load_skill` 后读取本次启用 Skill 固定版本中的清单路径，并检查当前 Skill 仍启用；长文本按位置分段。会话恢复校验 Skill ID 和版本，失效摘要不再带入后续请求。全部管理操作要求站点管理员，审计记录字段和版本、不记录内容；并发更新返回 409，界面保留输入，明确放弃后才能重新加载。

每次请求固定启用 Skill 的摘要、正文和版本。支持工具的模型先收到摘要，任务匹配时按系统指令调用 `load_skill`，加载请求固定正文。修改影响后续请求；停用或删除阻止尚未开始的加载。已加载内容不能撤回。工具结果只保存安全的名称、ID 和版本到活动记录，不新增独立费用。摘要与正文计入模型输入预算。

配置版本纳入压缩检查点的有效范围，当前请求使用固定配置，后续请求不会复用旧配置摘要。账号、会话及知识库授权仍独立校验；Skill 不能扩大权限。无工具能力模型正常问答，不注入 Skill。模型选择加载是概率行为，不能仅凭保存成功宣称方法已应用。

个人 `AgentSkill`、附件、MCP 数据和历史会话选择保留，不自动发布。#64 恢复私有 `/agent/*` 与会话选择接口，旧 `?extensions=1` 转入 `/extensions`；升级时旧个人扩展停用并清除有效 MCP 授权，既有会话首次恢复的新选择为空。无效版本或撤权后的历史工具内容不再进入后续请求。不提供旧 `read_skill_file` 或命令执行工具。

## 建议收件箱

工作台侧栏“意见反馈”提供功能建议、使用问题及其他，说明 1–2000 字。只记录当前账号、工作区、文字与时间，不自动收集会话、文档、图片或日志。

认证 `POST /suggestions` 使用请求 ID 幂等，响应丢失后重试返回同一条记录；相同 ID 不同内容返回 409。每账号每分钟最多 3 条，跨工作区合计，重试不占次数。数据库账号锁串行化限流与去重。

`/admin/feedback` 复用 `/site/admin/suggestions` 的分页、文字搜索、分类与状态筛选。详情纯文本显示，状态为待处理、处理中、已处理；版本冲突返回 409，记录处理者及时间，审计不记录说明正文。普通用户没有收件箱或他人建议读取权限。与回答点赞点踩完全分开。

## 数据与恢复

迁移 `0038_platform_skills_suggestions` 只新增 `site_skills` 和 `product_suggestions`；`0039_site_skill_files` 新增平台 Skill 资源表，保留已有 Skill ID、正文和版本，不接入旧个人附件。两项迁移均不修改旧扩展、账单或会话。重复请求唯一约束是 `(user_id, request_id)`。旧数据不公开、不回填。新表有数据时阻止破坏性降级，应保留数据并恢复兼容应用版本；部署前备份数据库、源文件和镜像，仅更新 API、Web。

### Skill 包补充验收（#62）

- ZIP 接受根目录或单层目录的 `SKILL.md`，保留 `references/`、`assets/` 下的文字、图片、脚本和普通二进制。ZIP/TAR 只检查成员路径、链接、特殊文件、数量及展开大小，不自动解压或递归展开。含 Linux 脚本、图片和普通资源的包可启用；Windows 脚本和程序仅保留为资源，不保证在 Linux 云电脑运行。文件检查只验证结构与资源边界，不代替管理员内容审核，也不声称能识别正文中的全部语义依赖。文字、HTML、SVG 均只作文本预览，不执行。
- 定向测试覆盖导入、重复路径、目录越界、符号链接、文件大小、缺失引用、管理员权限、草稿资源保留、启用校验、版本冲突、请求固定、按段读取、停用、对话工具顺序和刷新。历史续传继续隔离个人扩展与失效平台版本。
- PostgreSQL 验证升级、重复升级、空资源表降级重升、旧 Skill 保留、已上传资源禁止破坏性降级；3 项并发保存、幂等和运行时检查通过。隔离数据库不触及正式用户内容与账单。
- Playwright 检查 ZIP 导入、正文与文件预览、未保存提示、替换草稿确认、错误保留输入、移除确认、刷新、键盘、reduced motion 和 1440/700/390px 布局；截图保存在 `output/playwright/skill62-*`，已人工复查。
- 使用现有 `deepseek-flash` 和真实连接，在隔离数据库导入、启用测试包并提问；三轮调用实际完成 `load_skill`、`read_skill_resource`，遵从仅在补充资料出现的结尾标记，活动刷新可恢复。测试工作区账务为 0.8327 积分，未计入正式用户余额；不保证所有模型每次都主动加载。
