# 平台文字 Skill 与意见反馈

关联 Issue：#61。范围是平台文字方法、关闭个人扩展以及文字建议收件箱；不包括代码执行、附件、MCP 管理、管理员回复或通知，不改变 OCR、模型配置及计费规则。

## 管理与使用

站点管理员在 `/admin/skills` 搜索和筛选，进入独立详情页编辑名称、用途与 Markdown 指令。名称最多 64 字、描述 1024 字、正文 50000 字；新建默认停用。“保存并启用”可同时发布。单个 UTF-8 `.md` 导入兼容 SKILL.md frontmatter，只填充草稿；无描述时需补填。不读取附件或外部图片。

`/site/admin/skills` 提供分页列表、详情、创建、版本化修改和删除；`/import` 只解析草稿。全部操作要求站点管理员，修改记录字段和版本，不记录正文。并发更新返回 409，界面保留输入，明确放弃后才能重新加载。

每次请求固定启用 Skill 的摘要、正文和版本。支持工具的模型先收到摘要，任务匹配时按系统指令调用 `load_skill`，加载请求固定正文。修改影响后续请求；停用或删除阻止尚未开始的加载。已加载内容不能撤回。工具结果只保存安全的名称、ID 和版本到活动记录，不新增独立费用。摘要与正文计入模型输入预算。

配置版本纳入压缩检查点的有效范围，当前请求使用固定配置，后续请求不会复用旧配置摘要。账号、会话及知识库授权仍独立校验；Skill 不能扩大权限。无工具能力模型正常问答，不注入 Skill。模型选择加载是概率行为，不能仅凭保存成功宣称方法已应用。

个人 `AgentSkill`、附件、MCP 数据和历史会话选择保留，不自动发布；`/agent/*` 与旧会话扩展修改接口返回 410，携带非空旧选择的新会话返回 422。新请求不读取历史选择，也不提供 `read_skill_file`、MCP 或命令工具。历史协议续传包含个人 Skill、MCP 或失效平台版本时，仅沿用历史回答正文，不再次输入旧工具内容。旧 `?extensions=1` 返回工作台。

## 建议收件箱

工作台侧栏“意见反馈”提供功能建议、使用问题及其他，说明 1–2000 字。只记录当前账号、工作区、文字与时间，不自动收集会话、文档、图片或日志。

认证 `POST /suggestions` 使用请求 ID 幂等，响应丢失后重试返回同一条记录；相同 ID 不同内容返回 409。每账号每分钟最多 3 条，跨工作区合计，重试不占次数。数据库账号锁串行化限流与去重。

`/admin/feedback` 复用 `/site/admin/suggestions` 的分页、文字搜索、分类与状态筛选。详情纯文本显示，状态为待处理、处理中、已处理；版本冲突返回 409，记录处理者及时间，审计不记录说明正文。普通用户没有收件箱或他人建议读取权限。与回答点赞点踩完全分开。

## 数据与恢复

迁移 `0038_platform_skills_suggestions` 只新增 `site_skills` 和 `product_suggestions`，不修改旧扩展、账单或会话。重复请求唯一约束是 `(user_id, request_id)`。旧数据不公开、不回填。新表有数据时阻止破坏性降级，应保留数据并恢复兼容应用版本；部署前备份数据库、源文件和镜像，仅更新 API、Web。
