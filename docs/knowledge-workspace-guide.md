# 知库使用指南

## 知识库与文档

知库以知识库为单位组织资料。使用侧栏的新建入口，填写名称和可选描述，
即可创建一个独立的知识库。侧栏支持按知识库名称搜索。

在文档视图中上传资料。支持 PDF、DOCX、Markdown、TXT、HTML、CSV 和 XLSX，
单个文件最大 100 MB。文件进入队列后，系统依次解析、切分并生成向量。
文档状态包括排队中、处理中、已就绪和处理失败。

点击文件名可查看已经解析的原文。文件名搜索仅筛选当前知识库的文档列表。

## 知识问答

切换到知识问答视图，输入问题并提交。系统会从当前知识库检索证据，
交由配置的云端模型生成回答。证据不足时应明确拒答。

回答下方的参考来源可以打开原文片段，查看文件名、字符位置和 chunk 标识。
引用用于核对答案，不意味着 AI 回答绝对正确。TRACE 标识可以复制，用于排查检索过程。

切换知识库会清空当前问答视图，并取消旧回答请求，防止混入其他知识库的内容。

## 回收站

删除文档会将其移至当前知识库的回收站，而不是立即永久删除。
删除后文档不应继续参与检索。进入回收站并使用恢复操作，可以重新启用资料。

## 当前运行方式

当前平台通过本地 Docker 运行，使用兼容 OpenAI 接口的云端模型服务。
界面展示真实的模型配置、文档状态和服务状态，不展示模拟处理进度。
