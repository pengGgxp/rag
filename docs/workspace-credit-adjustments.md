# 工作区手动积分调整

Issue #53。

目标：站点管理员从用户所属工作区或工作区详情，对该工作区增加、扣减整数积分。
积分仍由工作区成员共享，不建立用户余额，不修改充值订单、价格、倍率、计费开关或历史账单。

范围与验收：

- 复用积分账户、追加式流水及站点审计；必填原因，明确确认目标、变动和调整后余额。
- 仅站点管理员可操作，显式传递目标工作区，不改变会话工作区。
- 事务锁定账户，校验当前余额，拒绝负余额及整数溢出；重复请求不重复记账，
  同一请求标识改变金额或原因返回冲突。
- 手动增加不是支付成功，不创建或伪造充值订单；扣减进入累计扣减，不新增消费事件。
- 管理员可查看最近调整及操作者；普通积分流水仅显示调整类型与金额，不返回内部原因。
- 失败保留输入，余额变化需刷新并重新确认；网络结果不确定时重试原请求。
- 验证后台权限、CSRF、金额边界、幂等、并发、回滚、账户隔离及待结算金额不变；
  构建前端并在 1440/390px 检查确认、错误、键盘与焦点，执行 diff 检查。

不需要数据库迁移，不增加依赖或新的弹窗体系。
