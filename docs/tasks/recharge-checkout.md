# 充值收银台

目标：充值先选金额，再进入独立收银台选择付款方式；仅点击支付时创建订单。

范围：站点统一档位、自定义比例、付款方式到渠道的显式映射、报价校验、订单状态恢复、后台设置和迁移。保留原渠道配置与历史订单验签，不改余额、账单或已有订单。

不包含：线上部署、自动渠道路由、退款、对账和真实付款。

验收：刷新预览不下单；报价和付款方式变更可恢复；重复请求不重复下单或入账；新旧订单均可回调；PostgreSQL 迁移、支付回归、前端构建及 1440/700/390px 浏览器检查通过。

迁移默认从启用的易支付配置原样复制报价；多个启用渠道报价不一致时中止，不自动选择价格。无数据库渠道配置的首次安装使用环境草稿，保存后以数据库为准。
