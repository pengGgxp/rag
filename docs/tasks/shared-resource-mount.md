# 工作区资源目录直接挂载

目标：资源库和云电脑使用工作区固定 OSS 目录，取消每环境副本、启动下载及正文回传。

范围：资源上传、模型文件写入、图片产物、删除、历史版本、云电脑挂载与索引、已有文件迁移和线上发布。不改变云电脑单价、历史账单或知识库原文件。

规则：同工作区共享当前文件，跨会话修改彼此可见。命令完成后登记文件和版本；历史版本单独保留，不暴露在可写挂载中。历史快照由 OSS 服务端复制，不经服务器下载回传，不计模型下载额度。当前目录是持久数据，结束环境不得清空。

验收：工作区隔离；上传即挂载可见；新环境复用同目录；修改/新增/删除反映到资源库；历史引用不变；启动及保存不调用资源下载缓存；销毁保留文件；迁移与发布前备份，真实合成文件验证，保留未验收项。
