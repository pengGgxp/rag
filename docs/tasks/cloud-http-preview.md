# 云电脑 HTTP 成果预览

## 目标与范围

为当前会话提供一个独立域名的 HTTP 成果预览，支持后台服务启动、鉴权代理、刷新、前台续时和结束云电脑。复用现有云电脑计费、资源挂载与聊天活动；不支持 WebSocket、终端、远程桌面或自动重启收费环境。

## 验收

- 服务就绪后才返回真实入口；重复提交和响应丢失不重复启动。
- 预览仅会话所有者且仍有工作区权限时可访问，不向网页传递平台或供应商凭据。
- 可见窗口每 20 秒续租，租约 60 秒；后台请求和状态查询不续时，最长时限仍有效。
- 桌面右侧与窄屏全屏预览，展示费用、截止时间、刷新、新窗口、停止操作。
- 后端生命周期、网关安全、PostgreSQL 迁移、前端构建及 1440/700/390px 截图验收。
- 合成网页真实沙箱验证预算不超过 5 元，不调用真实模型；公网域名、证书、鉴权未验证不得声称上线验收完成。
