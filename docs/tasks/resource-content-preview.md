# 资源库内容浏览与预览

## 目标与边界

默认瀑布流并可切换列表；图片缩略图、PDF 分段阅读、Word 首次打开转 PDF。预览产物保存在独立 OSS 缓存前缀，浏览器持有按账号和工作区隔离的缓存。保留原文件、资源权限与实际下载字节计量，不改变商业价格、知识库解析或云电脑操作。

## 验收

- 真实文件的卡片、阅读面板、首次准备和失败状态；1440/700/390px 逐张审查截图。
- 相同内容去重生成，原对象改变或删除使缓存失效；预览产物不计资源容量。
- 传输按实际字节结算；浏览器命中不重复传输；Range、权限和失败恢复回归。
- Word 转换禁用网络、宏与外部资源，在受限进程中运行；无可用运行环境时明确未验收。
- 原开发范围为本地验收；2026-11-07 用户追加授权线上部署。
