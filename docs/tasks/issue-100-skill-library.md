# Issue #100 Skill 仓库与用户管理

## 目标

恢复普通用户可发现的 Skill 管理入口，提供平台 Skill 仓库的浏览、搜索、详情、下载和安装，并让用户在当前工作区资源库中查看、导入、修改和删除 Skill。

## 涉及范围

- 管理员维护平台 `SiteSkill` 包及其安全校验。
- 普通用户读取已启用的平台 Skill，下载包并安装到当前工作区。
- 安装副本、外部导入和资源库/云电脑使用同一份工作区文件。
- 安装来源索引、同名/重复安装冲突、工作区权限和幂等保护。
- 普通用户 Skill 管理页面、资源库可见性和相关文档。

## 不包含

- 第三方公共市场、用户投稿审核、评分、付费 Skill、自动更新或自动覆盖本地修改。
- 第二套目录挂载、发布副本、正文双写、历史内容版本或云电脑模板。
- 线上部署、自动合并、关闭 Issue、商业价格和线上业务数据操作。

## 验收标准

- 可浏览、搜索、查看介绍、下载和安装平台 Skill；重复安装不覆盖已有修改。
- 可导入外部文件夹/压缩包，保留嵌套 `SKILL.md`、图片、脚本和示例压缩包字节；危险路径拒绝。
- 管理入口、资源库和云电脑看到同一份 `.skill` 文件；任一入口修改或删除后，其他入口读取到最新状态。
- 只读成员可以查看/下载，编辑成员才能安装、导入、修改和删除；跨工作区隔离。
- 浏览、下载、导入和安装不启动云电脑；实际文件工具继续沿用既有云电脑规则。

## 验证方式

- 后端定向测试覆盖权限、幂等、冲突、安装副本隔离、导入安全和删除可见性。
- 前端类型检查、构建和 `git diff --check`。
- 使用本地临时 Docker 项目、临时账号/工作区和独立目录执行真实浏览器流程，检查 1440/700/390px、焦点、键盘、长名称和错误恢复。

## 本轮实现与验收记录（2026-11-13）

- 平台仓库已提供浏览、名称搜索、详情介绍、ZIP 下载和安装；安装副本写入当前工作区 `skills/<name>-<id>/`，重复安装返回幂等结果，已有修改不会被覆盖。
- 普通用户扩展入口已恢复，外部 ZIP 导入保留嵌套目录、脚本、图片和示例文件；资源库中的 `.skill` 文件可直接预览、下载、修改和删除。
- 真实本地 API + 前端浏览器流程已验证：平台 Skill 搜索/详情/安装、资源库同源文件、ZIP 导入、SKILL.md 预览、编辑后资源库读取最新内容、删除后扩展和资源库均不可见。浏览器截图逐张查看：`output/playwright/issue100/platform-search-1440.png`、`output/playwright/issue100/resources-1440.png`、`output/playwright/issue100/resources-700.png`、`output/playwright/issue100/resources-390.png`。
- 浏览器按钮触发的跨源 ZIP `fetch` 在本地 Playwright 夹具中记录了 CORS 失败；同一会话直接导航下载接口收到 200 和 ZIP 响应，接口响应包含正确的 CORS 头。该现象未在生产域名复现，保留为本地浏览器夹具限制，待人工 review 时关注。
- 本地浏览器验收未启动模型或云电脑；后端权限、幂等、冲突、导入安全和删除可见性由 `backend/tests/test_issue_100_skill_library.py` 及相关回归覆盖。
