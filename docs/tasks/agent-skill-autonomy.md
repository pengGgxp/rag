# Skill 自主使用与流程门槛清理

目标：按用户确认将个人 Skill 从会话勾选权限改为模型自动发现，移除脚本包挂载依赖本轮 load_skill 的流程门槛。延续隔离命令和跨轮资料读取修复。

范围：当前用户、当前工作区内已启用且完成启用确认的全部个人 Skill 自动进入请求摘要；按需读取正文和资料，不向提示词倾倒整包。执行器按请求快照只读提供可用个人包；每次执行复查权限和停用状态。`/` 为任务提示，个人 Skill 不再显示会话权限复选框。已有 skill_ids 只作历史字段，不限制可用目录。

保留：用户/工作区隔离、停用和撤权、清单路径边界、文件版本冲突、资源与费用预算、第三方 MCP 授权和题目工作台权限、入库确认及计费。非法路径指访问包外或宿主路径，不是禁止模型在受控工作区创建合理文件。启用状态是用户明确控制，不当作流程门槛取消。

验收：无手动选择即可读取本人 Skill；脚本包无需先 load_skill 即可使用，未启用/他人/其他工作区包不暴露；版本固定、撤权和只读不变。检查现有 UI 及提示词，执行针对性回归、构建、浏览器检查。不删除真实安全边界，不改价格和历史数据。

检查结论：移除个人 Skill 会话筛选、请求内 loaded 状态与执行包挂载的绑定；停用单个包不影响其他命令；个人 Skill 复选框和 `/` 保存选择前置调用同时移除。保留第三方授权、入库确认、权限及安全参数校验、路径边界、并发版本、调用预算和不确定结果不重放，这些对应数据、费用或真实副作用。
