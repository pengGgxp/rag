# 多供应商与图片任务

目标：扩展现有供应商管理，对话支持 Chat Completions、Responses、Anthropic、Gemini，图片支持 Images、Gemini、Responses。身份由运行时绑定，图片按规格张数计费并保存资源库。

边界：不建设账号池、自动路由、中转平台或独立生图页面；不调整现有文字价格与历史账目。默认图片模型只由管理员指定。

实施：供应商与协议 → 图片任务及计费 → 后台与对话界面。每个单元独立验证和提交。

验收：协议多轮/流式/图片测试、任务幂等和恢复、价格快照及权限隔离、PostgreSQL 迁移、前端构建、1440/700/390px 截图审查，真实图片生成/编辑与资源闭环。真实接口缺少凭据或商业价格未配置时明确记录，不宣称验收完成。

上线：验收后备份数据库、配置和镜像，协调 API/Worker/Web 更新。未通过真实闭环不关闭 Issue。
