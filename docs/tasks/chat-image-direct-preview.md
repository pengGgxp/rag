# 对话生图直连预览

- 目标：生成结果自动显示 OSS 缩略图，点击后申请原图链接并立即打开预览框。
- 范围：复用资源缩略图任务，新增鉴权短期图片直链接口；仅允许受支持的图片类型。下载按钮保留服务器计量链路。
- 不包含：Bucket 公有读、其他文件直链、商业价格调整、线上部署。
- 规则：直链不计作已实际传输的应用下载字节；OSS 费用仍存在。短期链接到期前无法即时撤销，签发时重新检查工作区权限、文件状态和修订。
- 验收：缩略图不返回原图地址，点击才签发原图；权限隔离、删除、修订冲突、缓存失效；页面加载/失败/刷新和响应式截图检查。

## 接口与费用

- 图片预览统一使用 `POST /resources/{id}/preview-access`，浏览器直接读取 OSS 原图，不再排队生成或复用服务端缩略图。
- 点击时提交 `original: true` 和当前 `revision`，重新鉴权并校验当前图片，返回 90 秒原图链接。仅 PNG/JPEG/WebP；不允许任意对象键及其他文件。
- Bucket 保持私有；页面直接加载对象，不携带知库 Cookie，也不创建虚假的传输结算。直链有效期内持有者可访问，权限撤销后不再签发新链接；已签发链接最多在有效期内仍可访问。
- 原文件下载、资源库原预览及其传输账务保持原样。本次不改数据库结构。
