# 隔离命令执行不依赖 Skill

目标：按用户确认移除运行命令前必须加载个人脚本 Skill 的门槛，支持平台方法及普通文件任务直接使用隔离执行环境。

范围：配置了执行器的工作区 admin/editor 可使用 run_command；不要求选择或加载 Skill。已加载个人包继续按请求固定版本只读提供，停用及归属检查保留。保留成员权限复查、执行器隔离、网络限制、资源配额、取消及结果不确定时不重跑；不允许 API 执行宿主 shell，不扩大知识库或 MCP 权限。

验证：无 Skill、仅平台 Skill、未加载个人 Skill 的命令执行；包固定版本和停用、viewer/撤权、执行器缺失、参数校验及原执行器安全回归。本次先完成代码和本地验证。

本地验证：脚本执行、扩展及 Agent 回归共 52 项通过；2 项需要真实 Docker 执行器及公网的测试本轮未启用，不宣称已完成真实容器验收。未修改执行器实现、数据库或前端；`git diff --check` 通过。尚未部署线上。
