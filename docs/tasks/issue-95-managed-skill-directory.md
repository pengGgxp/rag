## 2026-11-13 最新目标

以 Issue 最新正文与评论 6844349791 为准。Skill 包直接写入当前工作区资源目录，文件为唯一来源；模型通过 list_files、read_file、run_command 发现、读取和执行。权限沿用工作区共享规则，保留跨工作区隔离。

不包含：业务数据迁移或删除、自动合并/关闭 Issue、部署、付费模型或云电脑调用、模板/IAM 修改。既有数据库历史包不自动搬运到共享目录；需要重新通过导入入口导入，避免静默公开原私有数据。

验收：隔离工作区上传合成包后，普通资源目录确有原文件及相对结构；通过现有文件工具读取和本地容器执行相对资源脚本；普通文件修改/删除随后可见；缺失 Markdown 引用允许导入；危险解包拒绝；跨工作区拒绝；额度和既有文件工具回归通过。执行前后端构建与 git diff --check。
