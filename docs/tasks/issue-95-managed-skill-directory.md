## 已确认目标

维护者在本任务确认取消说明中的引用路径存在性门槛，系统和个人 Skill 的实际文件放入资源库，用户侧默认隐藏，个人 Skill 保持私有。维护者选择方案 A：继续由现有管理页上传和编辑，目录自动同步，用户和模型不能绕过管理页修改发布内容。实际目录名使用 `skill-packages`。

## 范围与实现边界

- 管理页和现有数据库版本继续作为发布源；不存在的引用文件在实际读取时返回错误，不阻止导入、保存、启用或发现。保留路径穿越、压缩包安全、编码、体积、授权和版本冲突保护。
- 执行环境默认获得本次请求授权的全部系统及个人 Skill，不要求预先选择或加载。每次执行前同步真实文件，并重新核对当前启用、个人归属和工作区；请求内保持原包字节与版本。
- `skill-packages` 是资源库路径下的独立只读挂载。底层对象前缀按工作区、用户和执行环境隔离，位于共享资源前缀之外；不能只依赖目录隐藏或用户 ID 子目录保护个人包。只读同步失败时不执行用户命令。
- 普通资源列表、搜索、附件、引用和下载不暴露托管目录；模型通过方法工具或本人的执行环境读取。普通共享资源路径不能占用或修改 `skill-packages`。
- 发布更新在后续请求/调用准备时自动同步，执行中的请求使用已固定版本；停用和撤权在真正执行前复核。同步不启动额外云电脑，不重复计算原包的存储额度。
- 不实现直接改目录生效，不改变现有权限、资源原件、计费价格、检索/引用或删除规则，不执行业务数据迁移、付费调用或线上部署。旧云电脑没有隔离只读挂载时要求结束后重建，不维护双运行路径。
