# 资源库与云电脑共用目录

目标：资源库和云电脑共用工作区 OSS 挂载目录，仅维护当前文件索引，不在命令结束后扫描正文、复制归档或生成历史版本。

范围：上传、文件工具、资源列表/下载/删除、聊天附件当前引用、容量计量与一次性迁移。知识库文档使用独立对象，文档版本和历史账单不变。用户后续授权部署线上，存储套餐采用建议售价；云电脑维持现有 2 积分/分钟。

验收：上传与挂载路径相同；命令完成和销毁无文件同步；目录元数据刷新可发现新建、修改与删除；旧聊天引用删除后不可恢复；跨工作区隔离；迁移预检阻止冲突与缺失并可续跑；后端回归、前端构建和 diff 检查。真实 OSS/沙箱及 PostgreSQL 验证单独记录实际结果。

约束：任意 shell 写入由 OSS 挂载完成，不能由应用逐次阻止超过容量；容量检查以 OSS 元数据为准，超额时阻止新上传和新的写命令。运行中的任意命令仍可能超过额度，不能宣称有文件系统硬配额。
