# 文档批量导入

目标：文件多选、文件夹和 ZIP 都能预览后逐文件上传，取消静默截断，沿用原文档上传、权限、容量、去重、版本和计费。

范围：复用现有上传 Dialog、队列和分片直传；浏览器本地展开 ZIP，不持久化压缩包。相对路径用于预览和任务辨认，知识库仍保存独立文档，不新增目录树。新版本上传仍只接受一个普通文档。

限制：每批最多 200 个有效文档、合计 500 MiB，单文件及 ZIP 最大 200 MiB；ZIP 最多 2000 个条目，不递归展开嵌套压缩包，拒绝加密、危险路径、符号链接、损坏及膨胀超限。不支持 RAR、7z、TAR，跳过项目逐项反馈。

不包含：线上部署、修改价格或 OCR 策略、知识库文件管理器、服务端通用解压服务。

实现：新增非 UI 依赖 `@zip.js/zip.js`，现有依赖无 ZIP 读取能力；独立模块封装并按需加载，后续可替换而不改变入库接口。实际解压输出继续计数并检查 CRC，不仅依赖头部声明。

验收：多于 20 个文档不丢失；文件夹包含子目录；ZIP 支持中文目录和同名不同内容文档；不支持、空文件、超限及安全错误明确反馈；单任务失败不阻塞剩余队列；关闭或切换工作区不串任务。执行安全单元测试、现有上传后端回归、前端构建及 1440/700/390px 浏览器检查。
