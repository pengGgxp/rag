# Issue #138：知识库原件与工作区共享目录

## 目标

让知识库原件直接位于工作区 `知识库/<名称>/` 目录，使知识库、网页文件管理和已启动的云电脑读取同一份当前文件；让 Agent 能发现文件、按原路径读取并在用户明确要求时触发入库。新增与替换进入解析、切块和向量化流程，同库移动复用已有文档和向量。

## 范围

- 为知识库建立稳定的工作区目录，并将新上传和既有活动原件关联到共享对象路径。
- 暴露知识库文件目录查询与显式同步工具；原件正文沿用现有文件工具。
- 将共享工作区中的新增、替换、移动、删除、恢复接入知识库同步；保留历史原件、文档版本、切块、向量和引用。
- 统一解析/嵌入任务派发及排队任务恢复，保持任务可重试、重复同步幂等。
- 检索轨迹与回答引用返回工作区相对路径和文档版本 ID，支持从引用打开对应原件。

## 不包含

不改变检索范围、证据阈值或引用定位规则；不增加新的解析器、沙箱挂载方式、文件读取工具或模型服务；不迁移跨工作区数据、不部署、不关闭 Issue。

## 权限与迁移影响

原件进入工作区共享目录后，读取范围沿用工作区文件权限；工作区成员可读，编辑成员可整理或修改。知识库检索、文档状态和知识库元数据仍执行现有知识库权限检查。**曾设置为受限的知识库，其当前原件将变为当前工作区成员可读**，这是 #138 明确选择的共享语义；限制检索访问不会限制工作区原件读取。

迁移按需执行：首次同步或列出既有知识库文件时校验并关联活动原件，历史文档版本、chunk、向量和引用身份保留。完成前未对外部或生产数据执行迁移。

## 验收

- 上传后，工作区文件目录、知识库文档和共享存储指向同一原件；任务只入队一次。
- 同库移动及分类目录改名保留文档、chunk 和向量；跨库移动更新所属知识库。
- 正文替换保留旧版本，等新版本处理就绪后再切换活动版本；删除停止召回，恢复复用已解析文本和可用向量。
- 排队任务在维护恢复时从解析或嵌入正确阶段重新派发；失败可重试，重复同步不重复生成版本或向量。
- 工作区其他成员可按共享路径读取原件，其他工作区不能读取；检索及知识库元数据权限继续生效。
- 引用记录版本 ID 和工作区路径，原件预览按被引用文档版本授权。
