## 验收与验证

- 已完成文件说明名称和用途；没有单文件页面入口时，提供现有资源库页面及工具活动下载指引。
- 已就绪网页使用工具返回的预览页面链接；不得将 API 下载地址、本地路径或供应商地址当作用户页面入口。

- 知识库写入区分已提交与可检索，使用工具返回的页面入口。
- 简单问答无需套用交付模板。上下文重建后仍保留交付要求。
- 使用模拟模型验证工具结果和真实入口进入下一轮模型上下文，运行相关 Agent、上下文与工具回归及 `git diff --check`。模拟测试不代表真实模型行为已验收。
