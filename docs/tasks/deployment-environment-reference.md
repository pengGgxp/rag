# 部署环境变量表整理

- 目标：明确服务器环境变量与产品功能的对应关系，以服务器受保护配置为运行来源。
- 范围：中文变量说明、可复制的无密钥模板、配置校验、发布包及相关 CI 引用。
- 不包含：线上配置填充、重启或发布、商业价格变更、GitHub Environment 配置变更。
- 验收：变量目录与后端 Settings 一致；Compose 模板可实际渲染；说明区分构建参数、运行参数、发布派生参数和数据库设置；审计不输出密钥。
- 验证：部署模块单元测试、真实 Docker Compose `config --quiet`、`git diff --check`。
- 线上检查：2026-11-11 只读确认基础 app.env 有 35 个键，权限为 600；题库桥接密钥单独保存。未显式填写可选值不代表功能缺失，仍需结合默认值、发布派生值和后台数据库配置判断。
- 服务器写入尝试被 Xterminal 的 `SUDO_TOKEN_NOT_ALLOWED` 拒绝，未备份或修改线上配置；本任务不再尝试写服务器。
