# 云电脑接入与按量计费

目标：将脚本执行切换为阿里 Agent Sandbox，按用户/工作区/会话复用环境，接入持久化命令、资源同步、积分计量及后台配置。

范围：固定模板、按需文件输入、命令取消、闲置回收、结束环境、加密配置、可恢复状态及对话费用展示。不建设远程桌面，不回退 Docker，不改变资源库共享规则。

验收：模拟供应商覆盖生命周期、隔离、并发、重试及账务；PostgreSQL 迁移；前端构建与 1440/700/390 浏览器截图；真实云验证图片嵌入、连续命令、文档导出和销毁。真实调用需可用凭据与明确预算，无凭据不宣称验收或上线完成。

默认：闲置 600 秒，最长 3600 秒，每用户一个环境，站点并发 5。环境等待期间计费。用户授权先设初始价格，采用每分钟 1 积分，后台可修改；配置默认保持关闭。

状态：本地实现及模拟验收已完成，真实模板验收阻塞；尚未部署，不关闭任务。
