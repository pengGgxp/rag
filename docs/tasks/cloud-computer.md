# 云电脑接入与按量计费

目标：将脚本执行切换为阿里 Agent Sandbox，按用户/工作区/会话复用环境，接入持久化命令、资源同步、积分计量及后台配置。

范围：固定模板、按需文件输入、命令取消、闲置回收、结束环境、加密配置、可恢复状态及对话费用展示。不建设远程桌面，不回退 Docker，不改变资源库共享规则。

验收：模拟供应商覆盖生命周期、隔离、并发、重试及账务；PostgreSQL 迁移；前端构建与 1440/700/390 浏览器截图；真实云验证图片嵌入、连续命令、文档导出和销毁。真实调用需可用凭据与明确预算，无凭据不宣称验收或上线完成。

默认：闲置 600 秒，最长 3600 秒，每用户一个环境，站点并发 5。环境等待期间计费。用户授权先设初始价格，采用每分钟 1 积分，后台可修改；配置默认保持关闭。

状态：平台闭环及合成真实云任务已验证；网络拒绝规则和隔离强度未通过验收，尚未部署，不关闭任务。模板由管理员在阿里控制台创建，本项目只读取后台配置的模板 ID。

## 真实云验证与阻塞

测试预算上限为人民币 5 元，不调用真实模型。杭州提供的模板完成四次短时探测，均已确认销毁，硬期限每次 180 秒。图片插入 HTML 已验证；尚未取得供应商实际账单，不声称费用已核对。

提供的模板为 Python 3.13、1 核/1 GiB，缺少 LibreOffice。初期 pip 写入 `/home/user/.cloud-computer` 失败；拆分检查发现该位置会在安装最后复制 wheel 时返回 EIO，但同一模板的 `/tmp` 和普通路径可写。执行器已将运行期依赖、命令状态与日志改放 `/tmp/zhiku-cloud-computer`；正常资源工作目录与同步语义不变。

之后沿用用户授权的人民币 5 元预算，以既有模板完成真实云与平台服务联调：公共 PyPI 镜像 GET 200；安装 python-docx、Pillow、ReportLab 成功；输入资源图片按指定路径传入；连续命令创建含图 Word、HTML 和 PDF，再在下一命令修改 Word；服务生成并保存 resume.docx 的版本 1 和版本 2，下载旧版本仍一致、版本 2 内容不同，ZIP OOXML 检查包含嵌入图片；HTML/PDF/Word 都经平台资源下载接口取回。两次完整闭环初始 1 积分/分钟下，数据库 UsageEvent 分别实际结算 27 秒/0.4500 积分及 26 秒/0.4333 积分、剩余预留为 0，已请求销毁且供应商查询确认实例不存在；全程未调用模型。隔离服务测试库及对象存储为本地合成 fixtures，未触碰线上库或正式对象存储。实际阿里人民币账单仍需在控制台核对，未取得账单前不宣称实际花费已确认低于上限；停止新增付费实例。
