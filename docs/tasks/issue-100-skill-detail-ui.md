- 两页共用公共标题、概要、说明/编辑和文件区。平台说明不再继承管理员预览的300px最小高度；当前短说明实测约25px。我的 Skill 标签、实际清单路径在全宽编辑器上方，修改状态和保存按钮在下方，删除独立显示。

- 文件列表先刷新通用工作区索引，外部新增/删除自然反映；没有新增 Skill 安装状态或同步逻辑。回归覆盖新增、删除、目录标记过滤和跨工作区拒绝。
