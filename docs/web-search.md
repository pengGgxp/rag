# 联网搜索与计费（Issue #58）

目标：站点单独配置 DeepSeek Search/Fetch，向请求级模型注入内置工具；搜索、读取分别计价并沿用工作区倍率。模型与工具费用在一次请求中合计，四舍五入保留四位小数，不修改历史消费或其他商业配置。

使用官方 `https://api.deepseek.com/v1/tools/search` 与 `/fetch`，Bearer 密钥单独加密保存。Search 查询 1–128 字符，默认返回五条摘要；不传原始问题、用户 IP 或完整私有资料。Fetch 仅接受公开 HTTP(S) 页面，不跟随 API 重定向，保留 2 MiB 传输保护内的完整正文。网页正文属于不可信资料。

管理员通过 `/admin/search` 管理密钥、启停、超时、单次结果数和两项价格，不设置整轮搜索或读取次数上限。密钥不回显，空值保留，清除显式确认；缺价不补零，明确零价仍记录有效调用。价格支持每次或每千次，复用人民币成本、利润、费用分摊和支付费率换算。未配置时聊天保持可用，仅不注入联网工具。

长正文先保存在加密工具回执中，再按模型预算展示。`read_tool_result` 可按 Unicode 字符偏移、指定文本区域或字面查找续读，不重复联网或扣费。重新抓取属于新的观察，保留独立来源和抓取时间；历史观察不自动成为当前知识库证据。

官方资料核对时间：2026-10-30，参考 https://api-docs.deepseek.com/zh-cn/guides/search/ 。官方说明仅 HTTP 200 且搜索结果非空、读取有正文的调用收费，不按结果条数计费；本文不将官方价自动填入平台商业价格。

验收包括配置权限与脱敏、搜索与读取、逐次活动及独立网页引用、URL 与提示注入边界、模型与工具混合结算、快照、并发、取消、重放和恢复；执行后端、独立 PostgreSQL、Web 构建及 1440/700/390px 浏览器检查。真实密钥和价格由管理员填写；未完成两种回答模型的真实调用与账单验证前保持 Issue 打开。

## 结算与恢复

请求启动时保存两项工具价格、配置版本和工作区倍率。每次调用先锁定工作区账户及请求，检查累计消费、其他进行中请求和待结算金额，再登记唯一工具调用；完整有效结果加密保存后才继续 Agent。未确认的调用不重放，恢复时标记中断，不估算扣分。停用服务阻止尚未启动的工具，不抹除已经确认的消费。

模型普通输入、缓存读取、输出及有效工具调用均以有理数累计，统一乘请求倍率，合计只四舍五入一次到四位小数，明细按最大余数法分配。工具正文计入后续模型输入，但工具按次用量始终为 1，不按结果条数或正文大小重复收费。明确零价保留用量；无结果、错误和超时不收工具费。余额不足的已确认金额沿用待结算机制。

管理员测试只搜索一次，复用相同账务入口，使用请求 ID 防止网络重试重复收费。前端保留未确认测试的请求 ID；不自动重试上游，不创建虚假聊天回答。API 地址固定，不接受用户覆盖；API 重定向禁用，网页地址拒绝本机、私网及凭据。网页由 DeepSeek 远程读取，本服务不直接请求用户地址。

## 接口

### 来源收纳调整（2026-10-30）

目标：网页来源按工具调用位置展开查看，不在回答底部重复铺开；知识库参考来源默认折叠，保留正文引用和原文查看。范围仅涉及来源关联和呈现，不改变检索、权限、费用或历史引用。每个网页记录对应调用标识，同一网页可归属多个调用；旧来源无标识时收纳到首个网页工具。验收：流式及刷新后来源出现在正确工具内，键盘可展开，知识库来源默认关闭且能定位原文，390/700/1440px 无溢出；执行相关后端测试和前端构建。

验证：搜索/读取关联及刷新恢复后端测试通过，前端构建通过，Playwright 验证工具内来源、默认折叠、刷新、键盘及三种屏宽，截图 `output/playwright/source-fold-{1440,700,390}.png`。知识库折叠使用浏览器受控响应验证，不触发真实付费请求。

- `GET/PUT /site/admin/search`：站点管理员读取与版本化保存；`409` 必须重新加载，密钥不回显。
- `POST /site/admin/search/test`：已保存版本、请求 ID、当前管理员工作区结算。
- `GET /search/availability`：登录用户只读取可用状态，无密钥及价格。
- 对话发送增加 `web_search`，默认自动，关闭时不注入工具；不支持工具调用的模型不注入。
- SSE `web_sources` 与消息 `web_sources` 保存独立网页来源，知识库引用协议保持不变。
