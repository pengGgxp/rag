# 上下文入口简化

目标：默认仅显示已用百分比，移除 Token 明细、输出预留和安全余量说明；将 `/compact` 加入现有斜杠菜单，并保留付费确认及原有压缩权限、取消、失败处理。

范围：复用现有上下文组件和斜杠菜单。百分比展示估算输入占可用预算的比例，后端取消额外 5% 固定安全余量，仍保留配置的最大输出空间，自动整理阈值不变。不调整价格、模型默认选择、历史账单或权限。

验收：构建通过；预算测试覆盖正常及不足容量；浏览器验证百分比、斜杠筛选、键盘选择、取消确认保留草稿、加载及失败状态，以及手机布局。

后续补充：上下文面板显示“共 XXk · 已用 XXk”，1k = 1000，与工具栏百分比共用模型完整容量；没有估算时不虚构已用零值。后台配置 272k 时，展示总容量 272k，已用 53.4k 时百分比为 20%。最大输出限制仍只参与后端请求预算保护，不从面板总容量中扣除。验收覆盖三个屏幕宽度的容量文案与布局。
