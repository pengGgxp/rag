# Agent 自主执行

## 目标与范围

聊天由同一个 Agent 自主完成：直接回答、检索、改写查询、继续检索、
澄清或说明证据不足。不再用固定问答流水线或空引用判断覆盖 Agent 回答。

范围包括聊天提示词、工具执行、历史输入、停止操作和回归测试。
不增加新工具，不改变文档解析、版本、删除、工作区权限或积分计费模型。
独立的 `/knowledge-bases/{id}/answer` 是旧式证据问答 API，不是聊天 Agent。

## 执行约定

- 一份系统提示词贯穿工具调用和回答，内容在 `backend/app/agent.py`。
- 工具结果是候选资料，不是后端判定的“充分证据”。是否支持结论由 Agent 判断；
  私有事实缺少依据时仍须说明不知道，不能编造。
- 不限制 Agent 总轮数，不截断同一响应中的工具调用，不截断已完成的历史消息、
  工具查询或累计来源。来源按 chunk 去重，保留页码、坐标和版本。
- 检索工具的 `top_k` 由模型指定，省略时返回 20 条，没有固定最大值。
  这属于工具检索参数，不是强制 Agent 结束的条件。
- 非法工具参数返回错误让 Agent 修正；无效知识库 ID 不会悄悄扩大检索范围。
- 模型服务失败或不支持工具调用时明确失败，不静默切换成固定 RAG。
- 保留工具白名单、权限重校验、停止、删除、幂等、积分和网络请求超时。
- LangGraph 执行单轮模型/工具图，逐轮继续到模型返回最终回答，
  不通过提高框架递归上限伪装成“无限轮次”。

## 验收标准与验证

- 超过旧三轮、超过默认图递归轮数仍可继续；同一轮超过两个调用不丢弃。
- 检索为空时仍保留 Agent 自己的澄清或解释；一般问题不要求引用。
- 弱相关结果仍返回分数让 Agent 判断；超过八个来源可引用，重复来源去重。
- 历史和查询不再被旧字符数、消息数截断。
- 越权、删除、旧版本仍不可召回；停止和权限撤回后不再发起后续模型/工具调用。
- 工具调用错误不会触发另一个生成模型；失败和取消仍退款，可幂等重试。
- 后端回归测试、前端构建和 Docker 实际云端对话检查。

## 实际边界与风险

这不是物理上无限上下文：模型供应商仍有上下文窗口、内容策略、响应长度、
速率限制和网络超时；超出时明确报错，不静默丢历史。
连续调用不再有产品代码轮数上限，可能增加延迟和云端费用。
当前仍按请求固定积分计费，不是逐次模型调用计费。
停止会阻止后续调用，但不能撤回已经发往云端的同步请求，
最多需要等待该请求返回或触发网络超时。
证据充分性及不编造属于 Agent 提示词责任，不代表已有独立事实校验器。
