# 云电脑 HTTP 成果预览

模型使用 `start_preview(computer_id, command, port, name)` 在指定实例的共享工作目录启动前台 HTTP 命令。服务监听 `0.0.0.0`，端口 1024–49151（排除管理和数据服务端口），禁用热更新连接，用户手动刷新。启动器将服务独立进程组、启动意图、就绪结果及两路各 64 KiB 尾日志保存在临时目录。Agent 只等待最多约 25 秒的 HTTP 就绪，不等待服务结束。

每台云电脑一个活跃预览。命令请求摘要和请求 ID 复用原任务幂等控制，数据库唯一索引限制并发预览。启动响应丢失只检查原任务及进程；结果不确定不会直接重复运行。`stop_preview` 停止指定实例的服务，面板“结束运行”销毁该预览对应环境。取消其他命令不会终止预览。

## 域名与鉴权

- API/Worker 设置 `PREVIEW_ENABLED=true`，API/Web 的公开地址使用同一个知库域名。`PREVIEW_DOMAIN` 默认为 `preview.str1ct.top`。
- 独立进程 `uvicorn app.preview_gateway:app --host 0.0.0.0 --port 8001 --no-access-log` 使用 API 相同数据库和加密密钥；仅通过反向代理暴露，主机端口绑定 loopback。
- 泛域名 DNS 指向网关，证书覆盖 `*.preview.str1ct.top`；Nginx 示例为 `scripts/nginx-http-preview.conf`。
- 登录 API 返回 60 秒单次票据，兑换独立 Host-only Secure HttpOnly Cookie。数据库 Cookie 授权有效 120 秒，可见面板心跳续期；平台 Cookie、Authorization 和沙箱流量令牌不交给网页。
- 每次请求重新校验登录会话、成员身份、会话所有权、环境状态及最长时限。上游仅由已登记的实例端口构造，要求阿里返回流量令牌，不开启匿名访问。
- 2026-11-06 杭州真实端口验证：匿名为 403，`e2b-traffic-access-token` 请求为 200；SDK `e2b==2.31.0`。
- 实测阿里会将流量令牌头继续转发到目标进程，因此目标使用沙箱内 root 管理的入口转发器（独立高端口），剥离令牌后才转发给模型指定的应用端口。入口与网页进程分开，进程日志不记录请求头；网页实际端口不作为平台网关的上游。
- 网关允许普通 HTTP，拒绝 Upgrade；请求最大 16 MiB、响应最大 64 MiB，连接超时 5 秒、读写 30 秒、总传输窗口 60 秒。外部重定向被拒绝，站内跳转保留独立域名。平台鉴权头、网关 Cookie、转发头和上游跨域/后台 Worker 授权头被过滤。

## 计费与续时

不增加预览工具费，沿用启动时冻结售价和按秒累计费用。可见预览每 20 秒心跳，
授权租期 60 秒；心跳记录最后有效活动，闲置截止为最后活动加 600 秒，不额外叠加租期。
已有实例保持启动快照。活动命令不算闲置，最长时限不延长。
状态查询、积分页、网页请求不续时；隐藏、关闭或断线后恢复闲置回收，不自动启动环境。

状态源按用户、工作区、会话隔离，只核对消息引用的预览。
用户打开后才前台每五秒读取对应环境，不遍历工作区实例和历史命令。
心跳后重新核对，不直接用心跳响应覆盖终态。页面刷新不会创建新环境。
桌面、手机全屏和独立窗口都保留标题、刷新、关闭和“结束运行”，新窗口入口沿用原行为。
结束先确认“此预览将停止，已保存的文件会保留”，仅结束对应实例，
服务端确认前显示正在结束。确认框关闭恢复焦点，Escape 不连带关闭预览。
仅保留低强调的“预览运行期间计费”积分页链接，所有精确费用和时长在积分页查看。
只有服务端确认就绪才显示“打开预览”；历史失效显示“预览已结束”和文件入口。
结束中、终态及撤权后的迟到响应不能恢复 iframe。

## 运维与恢复

先备份数据库、环境配置、Nginx 和镜像，再迁移 `0060_cloud_http_preview`，更新 API、Worker、Web 及预览网关。原文件和历史账单不改写。回退代码前先结束预览环境，保留新增表便于核对，不删除资源文件。

手动 DNS 签发的泛域名证书不能无人值守续期，需要在到期前通过 DNS 验证续签；后续可配置最小权限 DNS API 自动续签，不将 DNS 凭据放入沙箱。
