# 供应商连接与模型

Issue #51，关联 #41、#44、#49。当前开发版直接切换，不提供迁移期界面。

## 归属与工作流

- 供应商连接维护调用类型、平台、名称、地址、加密凭据、超时、启停及版本。同平台可有多份连接。
- 模型引用一个连接，维护实际模型名、显示名称、思考能力、容量、最大输出和三项基准价。
- `/admin/models` 为供应商列表；连接详情默认显示模型，另有连接设置页签。
- 新建先保存连接，再获取候选或手动添加模型，集中配置能力与价格，原子保存草稿或启用。
- 获取列表不创建模型、不调用生成、不产生消费，不代表思考或工具兼容已验证。
- 已有模型的模型设置与价格共用保存和版本校验；价格继续复用人民币定价助手。
- 精确官方模型预设须主动确认应用；未知模型保持未配置，不猜测容量或能力。
- 请求级选择、默认模型引用、价格、倍率和结算开关不变。
- 新增时先选 OpenAI Chat Completions 或 OpenAI Responses，之后才填写其他信息。
  协议、流式及续传约定见 [调用类型](model-api-protocols.md)（Issue #52）。

## 接口与可靠性

- 站点管理员专用 `/site/admin/model-connections` 提供列表、创建、详情和版本化修改。
- `/{id}/models/discover` 读取已保存连接的 `/models`，不跟随重定向，限制十秒及 1MiB 响应。
- `/{id}/models` 在同一事务创建至多五十个模型；同连接不允许重复实际模型名。
- `/site/admin/llm-providers` 保留模型资源身份，写入引用连接及连接版本，可一次提交配置与价格。
- 密钥只写不读、留空保留；响应、日志和审计不包含明文或认证头。
- 配置版本不符返回 409；重复模型或缺失字段返回 422，失败不得清空输入。
- 请求固定连接、模型及思考配置，价格快照记录连接 ID 和版本。每次新上游调用检查原请求连接是否停用。
- 有模型的连接不得删除；停用连接使全部所属模型不能开始新调用。

## 迁移与发布

Alembic `0033_model_connections` 为每个现有模型创建独立自定义连接，不按名称、地址或密钥合并。
保留密文、超时、模型启停、ID、能力、价格、默认引用及历史关联。运行时只读连接表，删除模型的重复连接字段。

先备份数据库、配置和镜像，构建并验证候选 API/Web，再短暂停止新模型任务、排空、迁移和替换 API/Web。
不修改 `.env`、Worker 或数据服务。新增消费后不得回退到忽略连接和新快照的 API；保留新增结构并发布兼容修复。
