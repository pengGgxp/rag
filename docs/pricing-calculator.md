# 人民币定价助手

关联 Issue：#47。

## 任务范围

在模型基准价、平台 OCR/Embedding 基准价及新模型初始价中复用按成本计算入口。
站点管理员填写每单位人民币成本、目标利润、其他费用分摊及支付费率，预览并明确应用积分价格。
支付费率默认 0.1%，支持修改；工作区倍率仅用于收益试算，不修改任何工作区。

不调整充值套餐、支付渠道费率、现有商业价格、余额、历史消费、计费算法或 Issue #36 开关。
计算与预览只读，应用仅修改当前表单，仍需原来的保存操作。
不新增依赖、数据库结构、迁移步骤或另一套弹窗。

## 计算

所有金额使用十进制字符串输入，服务端使用有理数计算，最后对积分向上取整一次。

```text
R = 可用充值套餐中的最大（积分数 / 实付人民币金额）
目标售价 = （成本 + 其他费用分摊 + 目标利润）/（1 - 支付费率）
每单位基准积分 = ceil(目标售价 × R)
倍率后单位积分 = 每单位基准积分 × 试算倍率
倍率后预计收入 = 倍率后单位积分 / R
倍率后预计利润 = 倍率后预计收入 ×（1 - 支付费率）- 成本 - 其他费用分摊
```

报价基于当前支付配置中真实可用套餐，包括套餐所含赠送积分。
没有有效套餐时不能虚构兑换比例，提示先配置充值套餐。
本计算不估算额外活动赠送、税费及未知成本，不保证固定月成本全部收回。

计价单位显式填写，默认沿用正在编辑的单位。应用时一起更新单位大小与积分。
由于现有结算可能按单位进位，变更单位大小必须显示新单位及当前规则提示；
不能静默自动放大单位或将单位价格描述为单次请求扣款。
实际单价、支付手续费与预计利润预览保留小数，并显示取整影响和折扣亏损提示。

关闭不改价格；计算不触发表单提交；应用后遵循原表单未保存、保存与版本冲突流程。
