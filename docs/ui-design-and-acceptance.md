## 目标与边界

对应 GitHub Issue #10。根据用户要求，已通过 Gemini 网页版咨询 UI 设计。
提供给 Gemini 的仅为通用产品能力和界面问题描述，不包含密钥、仓库源码或知识库原文。

采用建议：固定知识库侧栏、独立文档与问答视图、紧凑表格、清晰的内容层级、
按需查看引用、移动端折叠导航。实现使用现有 Next.js 与 React，图标使用 Lucide。

不采用建议中依赖未实现能力的模拟流式回答、虚构进度、假账户和虚假系统指标。
本次不改变后端模型、检索策略、文档版本、删除语义或认证边界。

## 交互约定

- 新建和上传使用原生模态对话框，支持焦点约束与 Escape 关闭；提交期间避免重复操作。
- 文档按实际状态显示，回收站单独列出软删除文档。
- 文档搜索仅搜索文件名，知识库搜索仅搜索知识库名称。
- 处理中的文档定时刷新；解析原文与引用片段可按需展开。
- 切换知识库取消问答请求，过期文档请求不能覆盖新知识库。
- 提交失败保留输入并显示错误；对话框内的错误直接显示在对话框中。
- 不在浏览器保存敏感文档或回答；刷新页面不保留对话。
