# 用户管理的 Agent 扩展

> 历史验收记录，已由 Issue #61 的[平台文字 Skill](platform-skills-feedback.md)替代。个人扩展接口已关闭，MCP 不再调用；旧数据及历史记录保留。以下内容不代表当前可用功能。

## 目标

用户可以管理自己的 MCP 连接与 Skill，在对话中明确选择使用哪些扩展。
Agent 自主发现、加载和调用已授权能力，不增加固定执行流程或轮数上限。

## 范围与设计

- MCP 使用官方 Python SDK，支持 Streamable HTTP 和旧式 SSE。
- 连接提供创建、编辑、测试/同步工具、逐工具授权、停用和删除。
- 凭据只在服务端加密保存，不回传浏览器、不写入模型提示词或审计日志。
- 工具默认未授权，新发现或定义发生变化的工具需要用户重新授权。
- 选择连接代表允许向相应第三方发送调用参数并执行已授权工具，可能包括写操作。
  不把远端自报的 readOnlyHint 当作安全证明；当前不提供逐次操作审批。
- Skill 是用户拥有的任务方法和资源目录，支持创建、编辑、文件夹/ZIP 导入、
  完整 ZIP 导出、停用和删除；单独的 SKILL.md 仍可导入。
  使用 Agent Skills 的 name/description frontmatter；列表只暴露摘要，
  Agent 通过 load_skill 按需读取入口与文件目录，再用 read_skill_file 读取需要的文本资源，
  不把所有指令和附属文件塞进系统提示词。
- Skill 脚本和二进制资源原样保存并可下载，但不执行脚本、不安装依赖、不运行任意 stdio 命令。
  详细边界与新增验收见 skill-bundles-acceptance.md。
- MCP 连接和 Skill 按工作区 + 所有者隔离，不向其他成员共享私有凭据。
- 每个对话保存选中的扩展；未生成时可调整。Agent 每次调用前重新校验配置和权限。
- 无知识库的普通 Agent 对话可用，知识库只是可选的一类工具。
- 外部工具的输出不会伪装为知识库引用；记录工具执行状态供用户复盘。

## 网络与数据边界

- MCP 只允许 HTTP(S)，禁止 URL 内嵌凭据、fragment 和连接配置中的 query 密钥。
- 默认禁止内网、回环、链路本地及云元数据地址；DNS 结果在建立连接时校验并固定，
  关闭环境代理和自动重定向。管理员可通过明确主机白名单接入受信任内网服务。
- SSE 的消息端点必须与原连接同源，认证头不能被重定向到其他站点。
- 密钥使用单独的 MCP_CREDENTIAL_KEY；启动时不自动生成临时加密密钥。
  管理员需备份该密钥，丢失后已有凭据无法恢复。无凭据的连接不依赖此密钥。
- 停用、删除、工具定义变化和用户停止应在后续调用前生效。
- 建立连接、重新核对远端定义后，在真正发送 tools/call 之前再次检查授权和停止状态。
- 工具 schema 必须自包含，禁止远端引用；认证值在工具目录和返回结果中也进行脱敏。
- 已发送的第三方写入无法由本平台撤回；不自动重试外部工具操作。

## 验收

- 用户完成 MCP 保存 → 同步 → 选择工具授权 → 选入对话 → Agent 实际调用。
- 用户完成 Skill 导入/编辑 → 选入对话 → Agent load_skill → 使用指令回答。
- 跨用户/跨工作区读取、修改、调用均被拒绝；停用配置不再可调用。
- 非法参数、MCP 错误及超时反馈给 Agent，不泄露凭据，不绕回固定 RAG。
- 恶意地址、DNS 变更、跨源重定向、工具定义变化有测试。
- 数据库迁移升级/降级、后端全量测试、前端构建、桌面/移动真实浏览器验证。

## 不包含

MCP OAuth 授权码流程、MCP resources/prompts、远端 sampling/elicitation、
Skill 脚本执行、插件市场和共享插件管理员体系。不将这些描述为已实现。
