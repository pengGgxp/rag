# 工作区 Skill 与个人远程 MCP

Issue #95（2026-11-13）取代此前 Skill 私有包和固定发布版本方案。MCP 仍属于用户和当前工作区，授权边界不变。

## Skill 普通资源文件

- `/extensions` 的 Skills 页签通过 `SkillImport` 导入当前工作区副本；`/admin/skills` 的导入预览和编辑维护平台源包，不向管理员工作区安装。工作区副本不再维护独立正文、启用草稿、发布版本或同步链路。
- `POST /agent/skills/import` 接受 UTF-8 SKILL.md 或 ZIP，`/import-folder` 接受目录文件。导入直接写入当前工作区 `.skills/<可读名称>/`，保留原始字节（包括 frontmatter）和相对结构，路径冲突时消歧。一次导入最多 200 个文件、单文件 5 MiB、总计 20 MiB、上传 ZIP 25 MiB。路径穿越、链接、特殊文件、重复路径及多根目录拒绝；Markdown 引用不存在不拦截。
- 工作区文件服务负责通用文件，不识别 Skill 或维护安装状态。Skill 服务调用通用文件服务；管理页和模型从当前文件发现，内容始终只有一份。浏览、导入、安装及普通消息不会启动云电脑。
- 所有工作区成员按现有资源权限共享；viewer 可读取，editor/admin 可导入、修改、删除，其他工作区不可访问。不通过隐藏目录提供权限隔离。
- 只自动发现 `.skills/` 的 SKILL.md，不跟随符号链接，不把根目录内示例重复注册。旧 `skills/`、`.skill/` 保持原位，用户可自行移动；名称和简介来自 frontmatter，返回 name/description/manifest_path/directory，同名不同路径分别展示。损坏或缺名称清单提供修复入口，不阻断其他 Skill。
- 每个新消息生成元数据摘要，经统一入口注入提示词；续传复用原请求，压缩后新消息重新发现。用户字段作为结构化目录数据，不能提升权限。模型按用途选用后以 read_file 读取完整说明及相对资料，再以 run_command 运行脚本。不预加载正文，不新增专用执行器。真正文件/命令沿用云电脑费用规则；应用自带方法（例如教师出题）仍可使用 load_skill。
- 平台源包由管理员维护，下载与安装统一构包，生成正确名称/简介/正文，其他资源字节不变。根据当前发现的 name 判断“工作区已有”，不比较整包或版本；存在时返回真实路径不覆盖，删除/移动/改名自然改变状态。历史 WorkspaceSkillInstall 保留，新流程不靠它决定安装状态，也不建立替代安装表。用户副本与源包、其他工作区隔离。
- Skill 编辑使用真实 revision，冲突保留草稿；删除展示目录影响及确认标识；“在工作区查看”直接定位真实目录。未保存离开有确认保护。
- 历史数据库中的个人/平台包保留，不自动搬到共享资源中；避免静默公开原私有内容。需要使用时重新导入。历史包仍按原存储统计计入保留数据，新导入只计普通资源一次。

## MCP 连接与授权

- `/agent/mcp` 提供私有版本化管理，`/{id}/sync` 只使用已保存连接发现工具。仅 HTTP(S)，不跟随重定向，DNS 校验并固定目标地址，禁止私网、云元数据和跨源认证转发。
- 复用官方 MCP 客户端；发现最多 100 项，定义最多 512 KiB，原始响应最多 2 MiB，结果最多 512 KiB。拒绝压缩响应以防解压绕过体积限制。执行沿用服务超时，每次问答最多 20 次远程调用，无自动重试。
- 凭据加密、不回显。优先使用既有 MCP 加密密钥，未配置时复用站点配置加密密钥；不新增 `.env` 配置。凭据、正文和结果不进入审计或日志。
- 获取工具不等于授权；必须逐项勾选并明确确认自动调用、外部读写删除和可能的第三方费用。新工具、定义变化、地址/协议/凭据变化须重新授权；名称修改不撤销授权。
- 请求固定连接、定义和授权版本，每次实际调用前重新检查账户、当前工作区、启停及授权。工具使用稳定 ID 命名空间，不按名称合并。参数按自包含 JSON Schema 校验，描述和返回均为不可信资料。

## 重试、历史与迁移

- `0040_personal_extensions` 增加配置版本、限制确认、授权版本、会话初始化标记及远程执行记录。旧个人包、文件和历史字段保留，旧扩展统一停用，MCP 有效授权清空；旧会话对新请求的选择为空。
- 远程执行先持久化意图，确认后加密保存结果。相同回答、工具及参数的重复调用复用结果；未确认、取消或进程中断的操作不能重放，需先核对远端。相同参数的有意再次操作需新发一条消息。进程启动把运行中操作标为结果不确定。
- 远程执行记录随消息删除。已存在操作记录时禁止破坏性降级，恢复需使用兼容应用并保留数据。
- 历史续传和压缩检查点包含所选扩展版本及授权范围；撤权或配置变化后不复用旧工具数据。普通回答文本保留。已确认模型用量继续走原账务链路。
