# 个人 Skill 与远程 MCP

关联 Issue #64、#66。个人 Skill 仍属于用户和工作区；工作区文件目录对当前工作区成员共享。命令执行只有在独立临时容器执行器就绪并通过安全验收后才会向模型开放。

## 所有权与选择

- 个人扩展归属用户和当前工作区，所有读写、下载、预览和运行均校验两者。平台 Skill 继续由管理员发布、只读且自动发现。
- `/extensions` 为 Skills / MCP 列表，个人详情在 `/extensions/skills/{id}`、`/extensions/mcp/{id}`。旧 `?extensions=1` 转入新页面。
- 新会话在未显式选择时固定当时已启用的个人扩展；显式空数组表示不使用。已有会话保存自己的选择，新增加的扩展不自动加入。`PUT /conversations/{id}/extensions` 要求会话空闲。

## Skill 包

- `/agent/skills` 提供列表、详情、导入、文件夹导入、检查、文件读取、导出和版本化增删改。复用现有包解析器、路径、编码、压缩体积和文件数量限制，导入不落盘且只生成停用草稿。
- 个人包允许保留脚本和二进制；启用前确认一次相关限制，修改正文或文件后重新检查。脚本可由模型通过 `run_command` 在当前工作区的临时隔离环境中运行，可能读取或生成工作区输出；二进制资源仍只允许安全预览或下载，不作为模型可读资料。
- 工作区输出是 Skill 和对话脚本的临时产物，用户不能上传、编辑、重命名或删除；成员只能查看列表和下载结果。文件有容量上限并会自动过期清理，个人 Skill 包保持只读。
- 脚本只能通过临时执行器在工作区目录中运行；执行器负责容器隔离、资源限制、网络边界和凭据隔离，API 进程不得直接运行 shell。
- 模型先 `load_skill` 再 `read_skill_resource`；每次最多 12000 字，可按偏移续读。请求固定正文、清单和版本；停用或删除立即阻止尚未开始的读取。Skill 不扩大知识库及工具权限。
- 包内 Python、Node.js、Shell 脚本可按文字读取；加载结果返回当前请求的执行能力和只读包目录。只有已加载的个人包进入执行器 `/skills/{skill_id}`，目录保留完整相对结构及辅助资源，不写入共享输出。`run_command` 默认在 `/workspace` 运行，结果写回临时输出；不能修改原包。执行前重新校验 Skill 启停和用户权限，包内容使用请求开始时的版本。
- 输入框 `/` 搜索个人 Skill、平台 Skill 和已授权 MCP；选择个人扩展时先保存会话选择，再补入使用意图。平台 Skill 保持自动发现。箭头切换、Enter/Tab 选择、Escape 取消；加载和保存失败保留草稿，不擅自授权工具。
- 平台包仍使用严格启用审核，不因个人包放宽而改变。

## MCP 连接与授权

- `/agent/mcp` 提供私有版本化管理，`/{id}/sync` 只使用已保存连接发现工具。仅 HTTP(S)，不跟随重定向，DNS 校验并固定目标地址，禁止私网、云元数据和跨源认证转发。
- 复用官方 MCP 客户端；发现最多 100 项，定义最多 512 KiB，原始响应最多 2 MiB，结果最多 512 KiB。拒绝压缩响应以防解压绕过体积限制。执行沿用服务超时，每次问答最多 20 次远程调用，无自动重试。
- 凭据加密、不回显。优先使用既有 MCP 加密密钥，未配置时复用站点配置加密密钥；不新增 `.env` 配置。凭据、正文和结果不进入审计或日志。
- 获取工具不等于授权；必须逐项勾选并明确确认自动调用、外部读写删除和可能的第三方费用。新工具、定义变化、地址/协议/凭据变化须重新授权；名称修改不撤销授权。
- 请求固定连接、定义和授权版本，每次实际调用前重新检查账户、当前工作区、启停及授权。工具使用稳定 ID 命名空间，不按名称合并。参数按自包含 JSON Schema 校验，描述和返回均为不可信资料。

## 重试、历史与迁移

- `0040_personal_extensions` 增加配置版本、限制确认、授权版本、会话初始化标记及远程执行记录。旧个人包、文件和历史字段保留，旧扩展统一停用，MCP 有效授权清空；旧会话对新请求的选择为空。
- 远程执行先持久化意图，确认后加密保存结果。相同回答、工具及参数的重复调用复用结果；未确认、取消或进程中断的操作不能重放，需先核对远端。相同参数的有意再次操作需新发一条消息。进程启动把运行中操作标为结果不确定。
- 远程执行记录随消息删除。已存在操作记录时禁止破坏性降级，恢复需使用兼容应用并保留数据。
- 历史续传和压缩检查点包含所选扩展版本及授权范围；撤权或配置变化后不复用旧工具数据。普通回答文本保留。已确认模型用量继续走原账务链路。
