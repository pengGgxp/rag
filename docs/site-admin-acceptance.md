# 站点管理后台实现与验收

- Issue: [#33](https://github.com/pengGgxp/rag/issues/33)
- 日期：2026-10-26
- 范围：独立站点后台、用户与工作区运营摘要、停用/恢复/撤销会话、验证邮件重发、统一站点审计。
- 不包含：内容读取、密码/令牌查看、用户冒充、删除账号、手工调账、站点角色 UI 开关。

## 结构与复用

- `/admin/*` 使用独立持久布局；现有 `/admin/auth` 表单直接复用，不嵌套设置层。
- `admin-shell` 只负责站点导航与身份拒绝页；主工作台、工作区设置侧栏不复用为万能导航。
- `admin-ui` 只复用后台稳定的加载/错误/分页/积分摘要交互；现有业务组件没有站点列表的数据契约，因此新增这些业务组件。
- 操作确认复用现有 Radix Dialog；图标复用 Lucide，颜色沿用 Cobalt Token，无新增运行时依赖。
- URL 保存列表查询条件和页码，异步响应按请求序号防止旧结果覆盖新筛选；失败保留输入和导航。

## 安全实现

- 所有 `/site/admin/*` 接口复用数据库即时站点角色校验；工作区角色不提升为站点权限。
- 新增迁移 `0021_add_site_admin_console`：仅新增停用字段和站点审计表，保留所有用户、余额和工作区关系。
- 签发会话和停用操作对同一用户行加锁，防止停用期间并发签发会话；流式访问也复查账号状态。
- 管理员账号必须先由 CLI 撤销站点角色，才可停用，防止后台误锁站点入口。
- 重发验证邮件使用 30 分钟一次性随机链接，仅存摘要，链接 token 位于 URL fragment，不发送给 Web 访问日志，点击确认后 POST 消费。
- 首次邮箱所有权证明不代表旧密码可信：清除未验证旧密码、撤销旧会话，用户通过验证码登录后重新设密。
- Redis 邮箱/IP/站点限频失败关闭；同一用户重发间隔至少 60 秒，另有管理员 IP/目标 15 分钟限频。SMTP 失败不保留新令牌。
- 站点事件仅允许安全摘要字段，既有认证配置审计按安全字段回填，不返回密钥、Cookie、授权码或邮件正文。
- 保留最近 365 天；API 启动及每日清理过期记录，可手动执行 `python -m app.manage site-audit prune`。普通后台无修改/删除审计接口。
