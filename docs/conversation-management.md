# 会话管理与后台回答（Issue #76）

## 用户流程

新建只打开本地草稿，第一次发送才建立会话。保留模型、思考选择和知识库范围，清除本轮附件及扩展意图。文字、文档引用、已有资源引用及阅读位置按用户、工作区、会话写入标签页 sessionStorage，不保存文件正文；退出登录清除。草稿不是跨设备同步。

历史按置顶、今天、昨天、更早展示，每页 30 条。标题可原位修改，菜单提供重命名、置顶和删除。删除生成中的对话需确认，并停止该回答。Markdown 导出已从页面移除，后端接口本轮保留。

## API

- `GET /conversations?cursor=…`：`{items,next_cursor}`，置顶优先，再按消息活动时间和 ID 降序；重命名、置顶不改变活动时间。
- `PATCH /conversations/{id}`：`{revision,title?,pinned?}`；修订冲突返回 409，前端保留输入。
- `GET /conversations/search?q=…&cursor=…&since=…&until=…&knowledge_base_id=…&has_attachments=true`：每页 20 条，返回标题、活动日期、纯文本摘要和 `message_id`。标题命中优先。关键词使用参数化 ILIKE，并转义 `%`、`_` 和反斜杠。仅查询用户及回答正文，不查询思考、活动日志或附件内容。
- `POST /conversations/{id}/messages`、`POST /conversations/{id}/compact`：持久化幂等提交，返回 `{request_id,conversation_id,status}`。无须整理及旧请求的既有结果仍可直接返回 SSE。
- `GET /conversations/{id}/requests/{request_id}`：读取实际执行状态。
- `GET /conversations/{id}/requests/{request_id}/events?after=N`：读取加密持久事件并继续订阅，SSE ID 为 `request_id:sequence`。重连只续读，不重新 POST。
- `POST /conversations/{id}/stop`：明确停止回答，保留已有内容和已确认费用。独立图片任务、云电脑沿用原生命周期。

列表、搜索、详情、任务状态及订阅均校验本人、工作区及全部知识库权限；订阅持续重新检查会话和登录授权。

## 执行和恢复

既有 Celery Worker 执行 `execute_conversation`，既有 Agent 循环和计费服务保持不变。数据库请求记录唯一领取；配置、凭据及事件使用现有加密密钥保护。浏览器仅订阅，不拥有执行生命周期。页面卸载、网络中断、新建或切换均不发送停止请求。

生产者每 10 秒更新心跳；API 每 30 秒恢复队列，超过 2 分钟未更新的执行标记中断、释放会话槽位并核对用量。尚未开始的请求可再次投递，已开始且结果不确定的请求绝不重放模型或工具。Worker 运行异常也执行相同清理。每条请求内事件序号唯一。

自动标题在首次成功回答之后单独排队，无工具，只输入首条问题和首个成功回答的限长正文。历史标题不回填。请求开始时留下临时标题；标题生成失败或不可用就保留，已开始而结果未知时不重试。写回要求标题仍是临时来源且修订号未改变，手动命名不会被覆盖。

## 标题账务

`conversation_title_tasks` 记录模型、平台付款用途、真实返回用量或明确的估算来源。标题任务不创建用户预留、不调用普通回答结算器、不扣用户积分。当前模型没有供应商成本单价字段，因此成本参考明确标记 `unknown`，不把商业售价伪装成采购成本。以后有可靠成本数据时可基于保留用量核算。

## 部署与回滚

本次只开发及本地验收，不部署。后续部署需：

1. 备份数据库和配置，确认现有加密密钥可用于 API 和 Worker。
2. 暂停新回答并排空旧执行；不能对仍在运行的旧回答热切执行方式。
3. 执行 `alembic upgrade head`（0062）；历史标题标记为 `legacy`，余额、消息及账单不改写。
4. 同步更新 API、Celery Worker 和 Web，再恢复新请求。迁移失败不得启动新执行链路。
5. 核对提交、订阅、明确停止、切换后继续执行及平台标题账。回退前排空新任务，保留执行与账务记录，不自动重放请求。

## 本地验证

模拟上游，不调用真实模型。相关聊天、Agent、权限、附件、流式及账务回归通过；独立 PostgreSQL 验证迁移、历史余额与账本不变、并发只领取一次、事件及标题唯一约束。浏览器验证记录及限制见 `docs/tasks/conversation-experience.md`。
