# 注册赠送与站点公告

关联 Issue：#48。

## 范围

- 站点后台新增 `/admin/settings`，统一管理注册赠送积分和一条当前站点公告。
- 注册赠送默认保留 1000，允许 0–1000000 的整数；0 表示不赠送。
  只在新账号首次建立积分账户时生效，登录、加入工作区不重复赠送，
  修改配置不改变已有账户余额或历史账单。
- 公告支持标题、纯文本正文、发布开关；关闭发布后用户不可读取草稿。
  工作台三个模式共用紧凑公告条，详情复用 Dialog。
  用户关闭后不反复出现，同一用户可从侧栏重新查看；新版本重新提示。
- 普通成员和工作区管理员不能修改站点配置；保存需版本校验，修改写站点审计，
  不记录公告正文。草稿、加载、失败、重试和未保存确认复用既有组件。

## 非范围

不改充值、单价、倍率、消费计算或计费开关；不追溯补发/扣回积分。
不新增公告排期、多公告列表、富文本、附件、强制已读或第二套弹窗。
不改认证流程或工作区权限，不创建过渡期开关。

  不保存公告正文或凭据。
