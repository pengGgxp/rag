# 知库信息架构与工作区交互规范

- 状态：已确认，作为前端重构约束
- 适用范围：主工作台、知识库内部导航、知识问答、Agent 扩展、账号与工作区设置
- 关联 Issue：[#30](https://github.com/pengGgxp/rag/issues/30)
- 最后更新：2026-10-24

## 1. 产品层级

知库由四个相互独立的层级组成：

```text
主工作台
├── 知识库
├── 知识问答
└── Agent 扩展

知识库内部
├── 文档
├── 检索测试
├── 访问权限
└── 知识库配置

Agent 内部
├── Agent 对话
├── MCP 服务
└── Skill

工作区设置
├── 我的账号
├── 积分与充值
├── 计费规则
├── 工作区成员
└── 审计日志
```

主工作台、知识库内部和工作区设置不得互相嵌套。一个页面只负责一个层级，导航不能同时表达两个层级。

## 2. URL 与导航

保留现有外部入口，避免破坏书签和线上链接：

```text
/                         知识库工作台
/?chat=1                  知识问答
/?extensions=1            Agent 扩展
/settings                 我的账号
/settings/billing         积分与充值
/settings/policies        计费规则
/settings/members         工作区成员
/settings/audit           审计日志
```

导航规则：

- 使用 `Link`、`useRouter` 和 `usePathname` 表达路由状态。
- 不使用 `window.history.pushState` 或 `replaceState` 作为业务导航方案。
- URL、选中状态和实际内容必须保持一致。
- 浏览器刷新、前进和后退必须恢复同一页面。
- 兼容入口可以继续使用查询参数，但不得让查询参数成为组件之间隐式通信的唯一方式。

## 3. 主工作台

主侧栏只显示三个一级工作入口：

- 知识库
- 知识问答
- Agent 扩展

用户头像、当前工作区和设置入口属于账户/工作区菜单，不作为主产品导航项目重复出现。

主工作台不渲染账号、计费、成员或审计页面。

## 4. 知识库局部导航

进入知识库后，侧栏可以显示当前知识库的局部导航：

- 文档：导入、处理、版本、回收站和预览。
- 检索测试：验证检索结果和引用定位。
- 访问权限：管理员控制知识库成员访问范围。
- 知识库配置：基本信息和当前解析/Embedding 服务信息。

局部导航只影响当前知识库，不得改变工作区设置的路由或显示工作区管理页面。

## 5. Agent 扩展

Agent 扩展页面内部使用同一工作区，不创建第二个产品壳体：

- Agent 对话负责实际使用 Agent。
- MCP 服务负责连接、同步、授权和启停。
- Skill 负责多文件 Skill 包的导入、编辑、启停和删除。

MCP 和 Skill 业务组件优先复用现有实现，不为每个入口复制一套表格、弹窗或加载状态。

## 6. 账户与工作区菜单

主工作台底部只保留一个账户入口，入口内容包括头像、用户名和当前工作区。

打开后提供：

- 我的账号
- 工作区设置
- 切换工作区
- 退出登录

菜单必须：

- 使用可访问的按钮/菜单语义。
- 支持 Enter、Space、Escape 和方向键。
- 支持可见焦点状态。
- 不使用浏览器默认链接下划线。
- 菜单关闭后将焦点返回触发按钮。

设置工作台内部不再重复显示主工作台导航。

## 7. 加载与错误状态

- 全局壳体先显示品牌、侧栏和当前区域骨架。
- 数据请求只替换对应内容区域，不让整个页面白屏。
- 骨架屏不显示“正在恢复”等内部实现文案。
- 网络失败、未登录、无权限、空数据和处理失败使用不同状态表达。
- 错误状态保留可恢复操作和用户已输入内容。
- `prefers-reduced-motion` 下不使用强制过渡动画。

## 8. 渲染边界

本次采用混合渲染，不做全量 SSR 或后端 BFF：

- Server Component：页面元数据、静态路由壳体、静态导航和错误边界。
- Client Component：知识库数据、上传、流式问答、MCP/Skill、积分、成员和审计交互。
- 认证和 API 行为保持现有浏览器会话方式，避免引入新的会话转发层。

静态壳体和局部 skeleton 必须先可见，动态数据完成后再填充内容。

## 9. 组件边界

- `workspace-shell`：主工作台壳体和内容区域。
- `workspace-sidebar`：主工作台一级导航、知识库局部导航和账户入口。
- `knowledge-workspace`：知识库列表、当前知识库和文档工作流。
- `settings-page`：设置内容和 section 状态。
- `settings-sidebar`：设置工作台导航。
- 账户菜单只保留一个默认实现。

创建组件前必须先检索 `frontend/components/ui` 和现有业务组件。页面不得复制另一页面的完整壳体或导航实现。
