# 对话 Markdown 渲染

## 目标与范围

在现有 `react-markdown` 回答入口接入 `remark-gfm`，支持表格、任务列表、删除线、自动链接和脚注。复用已有引用插件和回答样式，保留原始 HTML 禁用策略。

本次只调整对话回答，不扩展 Skill 编辑器，不增加公式、高亮或新的模型参数。表格在窄屏独立横向滚动，不撑宽页面；任务复选框只读。

## 验收

- 桌面及手机检查表格、任务列表、删除线、自动链接和脚注跳转。
- 表格内知识库及网页引用保持可用，代码中的引用标记不转换。
- 流式不完整表格及恢复后的完整 Markdown 不导致渲染异常。
- 原始 HTML 和危险链接不能执行；执行前端构建及 `git diff --check`。

## 本地验证（2026-11-02）

- 前端构建及类型检查通过；Playwright 使用隔离模拟会话验证 1440、700、390px 的 GFM 解析、表格内两类引用、代码标记保留、HTML 与危险链接过滤及不完整表格。
- 脚注采用回答块独立 ID，保留页内跳转属性；不沿用外部链接的新窗口行为。
- 截图位于 `output/playwright/gfm-*.png`，已检查手机截图；原有文档提及与扩展选择回归通过。未使用真实模型生成作为验证依据。
