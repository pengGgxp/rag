# 工作区存储额度与套餐

## 目标与边界

为知识库原件、持久资源及个人 Skill 提供统一容量限制及可购买额度。
资源库统一聊天上传、独立上传与模型输出，不建设个人网盘或自动续费，不改变模型价格、倍率、充值比例或历史账单。

默认免费容量 512 MiB；每个北京时间自然月免费传输 512 MiB；有效资源不按年龄过期。
容量包与下载包有效期为购买后 30 天，各包独立到期，可叠加。
初始套餐为 5 GiB/1 GiB、20 GiB/5 GiB、50 GiB/10 GiB 和单独 5 GiB 下载；
参考售价分别为 3、10、20、6 元，积分价格必须由管理员明确保存发布，不假定充值比例。
套餐独立计价，不乘模型倍率；购买必须确认并在同一事务中扣款、授予额度。

## 计量规则

- 所有容量使用整数 byte。物理对象在一个工作区只统计一次，保留版本及待清理对象仍占容量。
- 个人 Skill 目前存放在数据库，按 UTF-8 正文和附件实际字节计入平台存储容量，不能称为 COS 用量。
- 分片上传初始化预留容量；入库复核并转换为实际占用。并发写入使用工作区行锁串行校验。
- 解析中间文件、备份不占用户额度；资源的模型读取、图片准备与执行输入按实际从对象存储读取字节消耗下载额度，缓存命中免费，解析链路维持原规则。
- 受认证控制的下载先预留额度，按 ASGI 成功发送的文件正文计量。HEAD、签名生成及未发送正文不扣额度。
- 用户在浏览器预览私有 OSS 文件时，由平台承担对象存储请求与流量费用；预览授权和直连读取不预留或扣减用户下载额度、积分。用户主动下载仍按 ASGI 实际发送的正文计量。相关接口、缓存及格式边界见 [`resource-content-preview.md`](resource-content-preview.md)。
- 支持单段 Range；重传重新计量；断开释放未发送部分。下载使用短租约和逐块检查点，异常恢复不永久冻结额度。
- 各包按最早到期顺序消耗，同到期时免费额度优先。现有购买不受后续改价、停用影响。
- 超额阻止新增及增加实际占用的写入；持续超额 30 天后按创建时间、ID 清理资源，绝不自动删除知识库原件。增加额度后重置计时。
- 删除先隐藏，异步删除无知识库引用的对象，实际对象删除成功才释放；失败保留并重试。同对象键只计一次，独立新版本按实际字节计量。
